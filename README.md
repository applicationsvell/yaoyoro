# ヤオヨロ合戦

式神と札で競う、五行の合戦。和風の対戦カードゲームです（ゴッドフィールドのような遊び方）。

## 遊ぶ

**https://applicationsvell.github.io/yaoyoro/**

- 「ひとりで練習」（CPUと対戦、2〜8人）と、合言葉でつながる「オンライン対戦」（最大8人・チーム戦もできる）が遊べます。
- スマホの縦向き・横向き、パソコンのどれでも遊べます。

### 合言葉でオンライン対戦する

1. 部屋をつくる人（進行役）：「部屋をつくる」→ 合言葉を決める（おすすめが自動で入ります。好きな言葉に変えてもOK）
2. 待合室の「合言葉を送る」で、LINE などに合言葉と参加用のリンクを送る
3. 参加する人：「部屋に入る」→ 同じ合言葉を入れる（リンクから開いた人は合言葉が入った状態で始まります）
4. 進行役が「合戦をはじめる」を押せばスタート。足りない席はCPUで埋められます

- 合言葉は3文字以上。ひらがな・カタカナ、全角・半角、空白や「-」のちがいは同じものとして扱います（「サクラ タヌキ 72」＝「さくら-たぬき-72」）
- 同じ合言葉の部屋がすでにあるときは「使われています」と出ます。別の合言葉にしてください
- 進行役のスマホが合戦を進めています。合戦中はアプリを開いたままにしてください（閉じてしまっても、開き直して「合言葉『…』の部屋に戻る」を押せば続きから再開できます）
- 参加者も、ページを開き直したら「部屋に戻る」で同じ席に戻れます

#### しくみ（くわしく知りたい人向け）

- 無料で公開されている MQTT の中継所 2 か所（`broker.emqx.io` と `broker.hivemq.com`）に同時につなぎ、片方が止まっても続けられるようにしています。サーバーを用意する必要はありません
- 合言葉から「部屋の番号」と「暗号のかぎ」を作ります。中継所には暗号にした盤面しか流れないので、合言葉を知らない人には中身が読めません
- 合言葉は中継所に送りません（部屋の番号は合言葉から作った別の文字列です）
- 無料の公開中継所は、動作の保証がありません。つながりにくいときは画面の上に「つなぎなおしています…」と出て、自動でつなぎなおします
- iPhone は iOS 16.4 以降が必要です（盤面を小さく縮めて送る機能を使うため）

### ホーム画面に追加する（iPhone）

1. Safariで上のURLを開く
2. 下の「共有」ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから開くと、全画面のアプリとして動きます。一度開けば、電波がなくても練習できます

Androidは、Chromeで開いて右上のメニュー →「ホーム画面に追加」です。

## 遊び方（かんたんに）

- 番が来たら、手札の武器で相手を攻める・道具や術を使う・よろず屋で買う・おみくじを引く、のどれかをします
- 札は**だれにでも使えます**（自分・味方・相手）。おにぎりで味方を回復したり、霊獣を味方につけたりできます
- 攻められたら守札で守ります。属性（木・火・土・金・水）の相性で、ダメージが1.2倍や半分になります
- 体力が0になると成仏。最後まで残った人（チーム）の勝ちです
- **ハプニング**（待合室で なし／ふつう／多め）：すっぽ抜け（攻撃がちがう人に飛ぶ）・会心の一撃（攻撃2倍）・巡のはじめの出来事（地震・お祭り・狐の嫁入り・魂の入れかわり など8種類）・ハプニング札（暴れ独楽・狸の化け葉・福笑い）。春一番のランダム攻撃は味方にも当たります
- くわしくは、ゲームの中の「遊び方」に全部書いてあります

## 開発メモ

| ファイル | 中身 |
| --- | --- |
| `src/part-*.js` | ゲームの部品（ルール・通信・演出・札の絵・霊獣の絵・画面） |
| `src/template.html` | 画面の骨組みとCSS |
| `src/gen_cards.py` → `src/cards.json` | 札・式神・天候・霊獣のデータ（`cd src && python3 gen_cards.py` で作りなおす） |
| `src/build.js` | アーティファクト版を `dist/yaoyorozu.html` に作る（テストはこれを使う） |
| `src/build-app.js` | アプリ版の `index.html`・`manifest.webmanifest`・`sw.js` を作る |
| `src/icon.js` | アイコン（`icons/`）を描いて書き出す（Playwright と Noto Serif CJK JP を使う） |
| `src/part-mqtt.js` | 合言葉のオンライン対戦（MQTT 3.1.1 over WebSocket の小さな実装・暗号・つなぎなおし） |
| `test/` | `node test/sim.js`（CPUどうしの自動対戦）と、Playwrightの画面テスト（`python3 test/run_test.py` など） |
| `test/rules_chaos.js` | 「札はだれにでも使える」「春一番」「ハプニング」のルールを1つずつ確かめる（`node test/rules_chaos.js`） |
| `test/chaos_vis.py` | 上のルールの画面を撮って確かめる |
| `test/online_mqtt.py` | 手元に中継所を2つ立てて、3台で合言葉のオンライン対戦をためす（中継所が止まる・開き直す・途中で抜けるもふくむ） |

作りなおすとき：

```sh
node src/build.js && node src/build-app.js
```

アプリ版は `window.APP_MODE = true` で動き、オンライン対戦は合言葉（`src/part-mqtt.js`）でつながります。
アーティファクト版（`dist/yaoyorozu.html`）は、これまでどおり Claude のアーティファクトの共有データベースでつながります。

合言葉のオンライン対戦のテスト：

```sh
python3 test/online_mqtt.py
```
